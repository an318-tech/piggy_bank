# Копилка — консольное приложение для управления накоплениями

Приложение позволяет создавать финансовые цели, отслеживать прогресс, управлять балансами и получать уведомления при достижении пороговых значений. Проект спроектирован с учётом возможности масштабирования: логика отделена от слоя хранения данных (в перспективе — замена JSON на PostgreSQL).

## Функционал

- **Добавление целей** с категориями. Реализован регистронезависимый ввод категорий: пользователь может ввести «техника», «ТЕХНИКА» или «тЕхНиКа» — система автоматически приведёт значение к каноническому виду («Техника»).
- **Управление балансом**: пополнение и снятие средств с проверками:
  - нельзя пополнить цель сверх целевой суммы (баланс автоматически ограничивается значением `target_amount`);
  - нельзя снять больше, чем есть на балансе цели.
- **Автоматическое изменение статуса**: при достижении 100% прогресса статус цели автоматически меняется на «выполнена».
- **Отслеживание прогресса**:
  - расчёт процента выполнения для каждой цели;
  - подсчёт общего прогресса по всем целям (К4).
- **Уведомления**: система проверяет достижение порога прогресса (по умолчанию — 50%) и выводит список целей, которые его превысили (К5).
- **Сохранение данных**: состояние приложения сохраняется между сессиями в формате JSON (`piggy_bank.json`) (К2).
- **Валидация ввода**: обработка некорректных значений (например, ввод букв вместо числа) без падения программы (К3).
